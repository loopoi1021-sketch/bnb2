# 6-4단계: Langfuse 대시보드 (코드로 생성)

> 시험 점수, 사용량, 속도, 비용을 한 화면의 차트로 본다.
> 화면에서 클릭해 만드는 대신 **코드로 만들었다** (Dashboard as Code). 다시 실행하면 같은 대시보드가 새로 만들어져서, 지우거나 다른 프로젝트로 옮기기 쉽다.

## 한 일

| 파일 | 설명 |
|---|---|
| `src/bnb2/dashboard.py` | 위젯 7개 정의(`WIDGETS`)와 대시보드 생성(`build`) |
| `src/bnb2/__init__.py` | `uv run bnb2 dashboard` 명령 추가 |

사용한 API는 Langfuse SDK의 `api.unstable.dashboards`와 `api.unstable.dashboard_widgets`다. 이름 그대로 **아직 실험 단계(unstable) API**라서 Langfuse가 바뀌면 고쳐야 할 수 있다.

## 대시보드 `bnb2 품질` 구성 (12칸 격자)

```
┌──────────────┬──────────────┬──────────────┐
│ 채점 분포      │ 환각률·검색   │ 질문 분류      │  ← 품질
│ (파이)        │ 적중률·차단율  │ (파이)        │
├──────────────┴───────┬──────┴──────────────┤
│ 질문 수 (일별)          │ 노드별 응답 시간 (p50)  │  ← 사용량·속도
├──────────────────────┼─────────────────────┤
│ Claude 비용 (일별)      │ Claude 토큰 (모델별)    │  ← 비용
└──────────────────────┴─────────────────────┘
```

| 위젯 | 데이터 (view) | 묶는 기준 | 값 | 필터 |
|---|---|---|---|---|
| 채점 분포 | 범주형 점수 | `stringValue` (correct/partial/…) | 개수 | 점수 이름 = `grade` |
| 환각률·검색 적중률·차단율 | 숫자 점수 | 점수 이름 | 평균 (true=1) | `hallucination`, `retrieval_hit`, `blocked` |
| 질문 분류 | 관측(observation) | 노드 이름 | 개수 | `retrieve`(문서 질문), `escalate`, `chitchat` |
| 질문 수 (일별) | 관측 | 시간 | 개수 | 노드 = `classify` (질문마다 1번 실행) |
| 노드별 응답 시간 | 관측 | 노드 이름 | 지연시간 p50 (밀리초) | 그래프 노드 6개 |
| Claude 비용 (일별) | 관측 | 시간 | 비용 합계 (USD) | 종류 = `GENERATION` (LLM 호출) |
| Claude 토큰 (모델별) | 관측 | 모델 이름 | 토큰 합계 | 종류 = `GENERATION` |

**질문 분류를 점수 없이 만든 방법**: 분류 결과를 따로 저장하지 않아도, 그래프가 **어느 노드를 지나갔는지** 세면 분류 분포가 나온다. `retrieve` 노드 = 문서 질문, `escalate` = 사람 판단, `chitchat` = 잡담이다. 5단계에서 노드마다 기록을 남겨둔 덕분이다.

## 검증: 위젯과 같은 조건으로 데이터 조회 (최근 7일)

같은 조건을 Langfuse Metrics API(`/api/public/v2/metrics`)로 조회해서 **차트에 실제로 데이터가 나오는지** 확인했다.

| 위젯 | 결과 |
|---|---|
| 채점 분포 | partial 3, correct 1, abstain 1 |
| 환각률·검색 적중률·차단율 | 환각 0, 검색 적중 0.2, 차단 0.2 |
| 질문 분류 | retrieve 9 |
| 질문 수 | 9 |
| 노드별 응답 시간 p50 | generate 1,402ms · check 1,393ms · classify 1,243ms · retrieve 61ms |
| Claude 비용 | $0.0058 |
| Claude 토큰 | claude-haiku-5-5 39,656 |

→ 7개 모두 정상이다. **속도의 병목은 Claude 호출 3번**(각 약 1.3초)이고, 검색(pgvector)은 0.06초다.

## 한계

- **데이터가 아직 적다.** 시험은 5문제, 질문은 9개뿐이다. 7단계(슬랙 봇)에서 질문이 쌓이면 사용량·속도·비용·분류 차트가 채워진다. 시험 점수 차트는 전체 시험(약 850원)을 돌려야 채워진다.
- `escalate`, `chitchat`이 0인 건 그 질문들을 Langfuse 연결(5단계) 전에 돌렸기 때문이다.
- **채점(Sonnet) 비용은 비용 차트에 안 잡힌다.** 채점 호출에는 Langfuse 기록을 연결하지 않았다. 차트의 비용은 봇 답변(Haiku)만이다.
- 8단계에서 👍/👎 피드백 차트를 추가한다.

## 🔍 직접 확인

**1) Langfuse 화면**: https://jp.cloud.langfuse.com 에서 왼쪽 메뉴 **Dashboards → `bnb2 품질`**로 간다.
- 차트 7개가 위 격자대로 배치돼 있다.
- 오른쪽 위 날짜 범위를 "Past 7 days" 등으로 바꾸면 데이터가 보인다.

**2) 다시 만들기**: 기존 대시보드를 지우고 새로 만든다. 위젯이 중복으로 생기지 않는다.
```bash
uv run bnb2 dashboard
```
