# 1단계: 인프라 (pgvector + Langfuse Cloud)

## 구성

```
 bnb2 앱 ──검색──▶ pgvector (내 컴퓨터, Docker, :5433)   문서 청크 + 임베딩
         └─기록──▶ Langfuse Cloud (jp.cloud.langfuse.com)  트레이스, 점수, 대시보드
```

| 파일 | 설명 |
|---|---|
| `docker-compose.yml` | pgvector 컨테이너 하나 |
| `.env.example` / `.env` | `DATABASE_URL`(pgvector 주소), `LANGFUSE_*`(Cloud 주소와 키) |

## 결정 기록: 셀프호스팅 → Cloud

처음에는 Langfuse를 Docker로 직접 띄웠다. 그런데 Langfuse v3부터는 셀프호스팅에 컨테이너 6개가 **필수**다.

| 컨테이너 | 역할 |
|---|---|
| langfuse-web | 화면 + API |
| langfuse-worker | 받은 트레이스 처리 |
| postgres | 사용자·프로젝트·키 |
| clickhouse | 트레이스·점수 저장, 대시보드 집계 |
| redis | web → worker 작업 대기열 |
| minio | 원본 이벤트 파일 보관 |

이 6개가 메모리를 약 2.6GB 썼다. 포트폴리오에 필요한 건 "대시보드로 품질을 보여주는 것"이지 Langfuse를 운영하는 게 아니므로, **Cloud 무료 플랜(Hobby)**으로 바꿨다.

| | 셀프호스팅 | Cloud Hobby (선택) |
|---|---|---|
| 내 컴퓨터 컨테이너 | 7개 (약 2.6GB) | 1개 (pgvector, 약 20MB) |
| 비용 | 무료 | 무료, 카드 등록 없음 |
| 한도 | 없음 | 월 5만 unit, 데이터 30일 보관 |
| 데이터 위치 | 내 컴퓨터 | Langfuse 서버 (일본) → 개인정보는 5단계에서 마스킹 |

**unit 계산:** 질문 1개 ≈ 트레이스 1 + 노드·LLM 호출 약 6 + 점수 약 4 ≈ 11 unit. 94문제 시험 1회 ≈ 1,000 unit이므로 한도에 여유가 있다.

**30일 보관 대응:** 결과는 대시보드 캡처와 파일로 git에 남긴다.

**JP 리전을 고른 이유:** 리전은 US, EU, JP 세 곳인데 한국에서 가장 가깝다. 코드는 같고 `LANGFUSE_BASE_URL`만 다르다.

## pgvector 설정

| 설정 | 값 | 이유 |
|---|---|---|
| 이미지 | `pgvector/pgvector:0.8.7-pg17` | Postgres 17 + pgvector 0.8.7. 기존 `bnb`와 같은 버전 |
| 포트 | `127.0.0.1:5433` | 내 컴퓨터에서만 접속 가능. 5432는 기존 `bnb`가 사용 중 |
| 계정 / DB | `bnb2` / `bnb2` / `bnb2` | 로컬 전용이라 단순하게 함 |
| 볼륨 `pgvector_data` | | 컨테이너를 꺼도 데이터 유지 |

테이블은 2단계(문서 적재)에서 만든다.

## Langfuse Cloud 가입과 키 발급

1. https://jp.cloud.langfuse.com 에 접속해 **Sign up**을 누른다 (Google이나 GitHub 계정으로 가입 가능).
2. Organization 이름을 정한다. 예: `bnb2`
3. Project 이름을 정한다. 예: `bnb2`
4. 프로젝트 화면에서 **Settings → API Keys → Create new API keys**를 누른다.
5. 아래 세 값을 `.env`에 붙여넣는다. **Secret Key는 이 화면에서만 보이니** 바로 복사한다.
   ```
   LANGFUSE_PUBLIC_KEY=pk-lf-...
   LANGFUSE_SECRET_KEY=sk-lf-...
   LANGFUSE_BASE_URL=https://jp.cloud.langfuse.com
   ```

## 🔍 직접 확인

**1) pgvector**: 아래 명령의 결과가 `vector|0.8.7`이면 성공이다.
```bash
docker compose exec pgvector psql -U bnb2 -tAc "select name, default_version from pg_available_extensions where name='vector'"
```

**2) Langfuse 키**: 아래 명령으로 내 프로젝트 이름이 나오면 성공이다.
```bash
set -a; . ./.env; set +a; curl -s -u "$LANGFUSE_PUBLIC_KEY:$LANGFUSE_SECRET_KEY" "$LANGFUSE_BASE_URL/api/public/projects"
```
