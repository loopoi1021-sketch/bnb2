# 7단계: 슬랙 봇 (Slack Bolt + Socket Mode)

> 직원이 슬랙에 물으면 4단계 그래프를 돌려 답한다. 공개 서버 없이 **내 컴퓨터에서** Socket Mode로 슬랙과 연결한다.

## 한 일

| 파일 | 설명 |
|---|---|
| `slack-manifest.yml` | 슬랙 앱 설정 (권한, 이벤트, Socket Mode). 붙여넣기 한 번으로 앱 생성 |
| `src/bnb2/slack.py` | 슬랙 이벤트 받기 → 그래프 실행 → 답변 보내기 |
| `src/bnb2/graph.py` | `answer()`: 질문 하나를 끝까지 처리하고 Langfuse에 슬랙 정보(질문자, 대화, 태그)를 붙임 |
| `src/bnb2/retrieve.py` | Voyage 한도에 걸리면 기다렸다가 재시도 |
| `tests/test_slack.py` | 멘션 제거, 담당자 멘션 조건 테스트 |
| `.env` | `SLACK_BOT_TOKEN`(xoxb), `SLACK_APP_TOKEN`(xapp), `SLACK_OWNER_ID`(담당자) |
| 추가 라이브러리 | `slack_bolt` 1.30 |

## 슬랙 앱 설정 (`slack-manifest.yml`)

| 설정 | 값 | 이유 |
|---|---|---|
| `app_mentions:read` | 권한 | 채널에서 `@bnb2` 멘션 받기 |
| `chat:write` | 권한 | 답변 보내기 |
| `reactions:write` | 권한 | 👀 / ✅ 진행 표시 |
| `im:history` + `message.im` | 권한 + 이벤트 | 봇에게 DM으로 묻기 |
| `app_mention` | 이벤트 | 멘션 받기 |
| `interactivity` | 켬 | 8단계 👍/👎 버튼 |
| `socket_mode_enabled` | 켬 | 공개 URL 없이 연결 |

**토큰 두 개**

| 토큰 | 모양 | 용도 |
|---|---|---|
| Bot Token | `xoxb-...` | 답변 보내기, 이모지 달기 (슬랙 API 호출) |
| App-Level Token | `xapp-...` (`connections:write`) | Socket Mode 통로 열기 (이벤트 받기) |

## 동작 흐름

```
👤 #채널: @bnb2 체크아웃 후 짐 몇 시까지 맡길 수 있어?
   │  (Socket Mode 통로로 app_mention 이벤트 도착)
   ▼
handle()
   ├─ clean(): "<@U봇ID> " 제거 → "체크아웃 후 짐 몇 시까지 맡길 수 있어?"
   ├─ 질문에 👀
   ├─ answer(): 그래프 실행 + Langfuse 기록 (user_id=질문자, session_id=채널-대화, tags=["slack"])
   ├─ make_reply(): 담당자가 봐야 하면 끝에 @담당자 멘션
   ├─ 답변 전송: 채널에서 물었으면 채널에, 스레드 안에서 물었으면 그 스레드에
   └─ 👀 → ✅ (실패하면 ⚠️ + "지금은 답변할 수 없어요")
```

| 결정 | 이유 |
|---|---|
| 채널 질문 → 채널에 바로 답 | 호스트 요청 (처음엔 스레드 댓글이었음). 스레드 안 질문은 대화가 흩어지지 않게 그 스레드에 답 |
| 태그 없이 묻기 = DM만 | 채널에서 모든 메시지에 답하면 잡담에도 끼어들고 비용이 든다. 전용 채널 방식은 필요하면 추가 |
| 담당자 멘션 조건 | `escalate`(사람 판단), 또는 문서 질문인데 근거 검사에서 막힘("찾지 못했어요") |
| 이모지 실패는 무시 | 진행 표시일 뿐이라 실패해도 답변은 보낸다 |
| 에러가 나도 답한다 | 봇이 조용히 멈추면 직원이 기다리기만 한다. ⚠️ 메시지로 알린다 |
| `session_id=채널-대화` | Langfuse에서 같은 대화의 질문들을 묶어 볼 수 있다 |

## 실제로 겪은 문제

**Voyage 한도 초과 → "⚠️ 지금은 답변할 수 없어요"**
- 원인: Voyage 무료 계정(카드 미등록)은 **분당 3회**. 1분 안에 질문이 3개를 넘으면 검색 단계에서 거절된다.
- 해결: 한도에 걸리면 **20초씩 기다렸다가 최대 3번 재시도**. 답이 20~60초 늦어질 수 있다.
- 근본 해결: Voyage에 카드를 등록하면 한도가 크게 풀린다. 무료 토큰 2억 개는 그대로라 사실상 과금은 없다.

## 🔍 직접 확인

**1) 봇 켜기**: 내 터미널에서 켠다. `Ctrl+C`로 끈다. 봇을 두 개 켜면 답이 두 번 간다.
```bash
uv run bnb2 slack
```

**2) 슬랙에서 묻기** (채널은 `@bnb2` 태그, DM은 태그 없이)

| 질문 | 기대 결과 |
|---|---|
| 체크아웃 후 짐 몇 시까지 맡길 수 있어? | "오후 2시 30분까지" + 📄 출처 |
| 근처 맛집 추천해줘 | "문서에서 찾지 못했어요" + @담당자 |
| 게스트가 하루 일찍 나간다고 환불해 달래 | "🚨 담당자 판단이 필요한 질문이에요" + @담당자 |
| 고마워! | 짧은 인사 |

**3) Langfuse**: **Tracing → Traces**에서 태그 `slack`으로 거르면 슬랙 질문만 보인다. User ID에 질문자의 슬랙 멤버 ID가 보인다.
